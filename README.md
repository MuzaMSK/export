## Deploy to GitHub Pages

### Option A - gh-pages branch (recommended)

    cd client
    npm install --save-dev gh-pages

Add to client/package.json scripts:
    "deploy": "npm run build && gh-pages -d ../export"

Then run once:
    npm run deploy

GitHub repo -> Settings -> Pages -> Source: gh-pages branch

### Option B - /docs folder on main branch

Rename this folder to docs (or set vite outDir to ../docs).
GitHub repo -> Settings -> Pages -> Source: main branch, /docs folder

### Option C - any static host

Upload contents of this folder to Netlify / Vercel / Cloudflare Pages / S3 / nginx.

## Before deploying - IMPORTANT

Edit client/.env.production:

    VITE_WS_URL=wss://your-server.com/ws

Then rebuild: 
pm run build

Otherwise the client will try ws://<page-host>:2567/ws which only works locally.
